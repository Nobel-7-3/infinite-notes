# Changelog

## 26 September 2026 — Android 4.7 · Windows 3.8.1

The first release from this repository.

**Android 4.7**
- Sync with the Windows app over a USB cable, in the direction you choose —
  tablet to laptop, laptop to tablet, or both. Notes, their media and deletions
  all travel. No Wi-Fi, account or cloud involved.
- Merge one note into another: long-press a note → *Merge into another note…*.
  It lands underneath, and nothing you wrote gets covered.
- Import Word documents (`.docx`) straight onto the canvas as pages.
- Google Drive sync removed from the tablet.

**Windows 3.8.1**
- USB sync carries media and deletions.
- Built on Electron 44, with current security fixes.
- The installer contains only the app. New installs keep notes in
  `Documents\Infinite Notes`.
- `adb` is found automatically.
